# GeneaTree Pro

Aplicación web estática de genealogía e investigación documental.

## Publicar con GitHub Pages
1. Crear un repositorio llamado `geneatree`.
2. Subir `index.html` a la raíz del repositorio.
3. Ir a Settings -> Pages.
4. En Build and deployment elegir `Deploy from a branch`.
5. Seleccionar `main` y `/(root)`, y guardar.
6. Esperar la publicación. La URL será `https://TU-USUARIO.github.io/geneatree/`.

## Importante sobre los datos
La aplicación guarda datos en LocalStorage del navegador. GitHub Pages publica el código, no sincroniza los datos entre computadoras ni usuarios. Usar siempre "Respaldo completo" y guardar el JSON fuera del navegador.

No subir respaldos JSON, actas, fotos de documentos ni datos personales al repositorio público.
